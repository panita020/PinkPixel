ชื่อทีม : PinkPixel
กลุ่ม : คภ.4/1
Developer A: โค้ด PHP ฝั่งเซิร์ฟเวอร์
- เชื่อมต่อฐานข้อมูล และออกแบบตารางฐานข้อมูล
- ระบบ Login / Logout แยกสิทธิ์ ครู / แอดมิน / นักเรียน 
- บันทึกการเช็คชื่อ และคำนวณสรุปสถิติ 
- ตรวจสอบข้อมูลจากฟอร์ม

Develpoer B: หน้าเว็บ ทดสอบ เอกสาร
- ออกแบบหน้าเว็บและ CSS ให้ใช้ง่าย
- ทดสอบระบบทุกกรณี เช่น Login ผิด เช็คชื่อซ้ำ นักเรียนเข้าหน้าครู 
- เขียนคู่มือการใช้งานและ README

ปัญหาที่จะแก้ไข : ผู้ดูแลชมรมต้องใช้เวลาในการตรวจสอบและสรุปจำนวนครั้งที่สมาชิกแต่ละคนเข้าร่วมกิจกรรมชมรม ซึ่งอาจเกิดความล่าช้าและข้อผิดพลาดได้ง่าย ส่วนนักเรียนก็ไม่สามารถตรวจสอบได้สะดวกว่าตนเองขาดกิจกรรมไปแล้วกี่ครั้ง จนอาจขาดเกินกำหนดโดยไม่รู้ตัว
ทีมจึงพัฒนาระบบเช็คชื่อสมาชิกชมรมผ่านเว็บไซต์ เพื่อให้ครูสามารถบันทึกสถานะการเข้าร่วมกิจกรรม ได้แก่ มา / ขาด / ลา ได้สะดวก ระบบสามารถป้องกันการเช็คชื่อซ้ำและสรุปสถิติการเข้าร่วมกิจกรรมได้ทันที อีกทั้งนักเรียนยังสามารถตรวจสอบประวัติการเข้าร่วมกิจกรรมของตนเองได้

ผู้ใช้ : 1. ครูที่ปรึกษาชมรมหรือหัวหน้าชมรม
   เข้าสู่ระบบเพื่อเช็คชื่อสมาชิกในชมรมที่ตัวเองดูแล และดูประวัติกับสรุปการเข้าร่วมกิจกรรม
2. ผู้ดูแลระบบ (Admin)
   ดูแลข้อมูลได้ทุกชมรม และดูภาพรวมการเข้าร่วมกิจกรรม
3. นักเรียน (สมาชิกชมรม)
   เข้าสู่ระบบด้วยรหัสนักศึกษา เพื่อดูว่าตัวเองมา / ขาด / ลา ไปกี่ครั้ง
   "# PinkPixel"
