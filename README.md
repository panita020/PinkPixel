ปัญหาที่จะแก้ไข : การเช็คชื่อสมาชิกชมรมยังใช้กระดาษ ทำให้เสียเวลา เอกสารหายหรือเสียหายได้ง่าย
เวลาครูอยากรู้ว่าสมาชิกแต่ละคนเข้าร่วมกิจกรรมกี่ครั้ง ต้องนับจากใบเช็คชื่อทีละแผ่น ซึ่งช้าและผิดพลาดได้ง่าย
ส่วนนักเรียนก็ไม่รู้ว่าตัวเองขาดไปแล้วกี่ครั้ง จนขาดเกินกำหนดโดยไม่รู้ตัว
ทีมจึงพัฒนาระบบเช็คชื่อสมาชิกชมรมผ่านเว็บ ให้ครูบันทึกสถานะ มา / ขาด / ลา ได้สะดวก
ระบบป้องกันการเช็คชื่อซ้ำและสรุปสถิติได้ทันที และนักเรียนเข้ามาดูได้เองว่าขาดไปกี่ครั้ง

ผู้ใช้ : 1. ครูที่ปรึกษาชมรมหรือหัวหน้าชมรม
   เข้าสู่ระบบเพื่อเช็คชื่อสมาชิกในชมรมที่ตัวเองดูแล และดูประวัติกับสรุปการเข้าร่วมกิจกรรม
2. ผู้ดูแลระบบ (Admin)
   ดูแลข้อมูลได้ทุกชมรม และดูภาพรวมการเข้าร่วมกิจกรรม
3. นักเรียน (สมาชิกชมรม)
   เข้าสู่ระบบด้วยรหัสนักศึกษา เพื่อดูว่าตัวเองมา / ขาด / ลา ไปกี่ครั้ง
